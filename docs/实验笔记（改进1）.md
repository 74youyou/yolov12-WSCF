# YOLOv12-WSCF v2 完整技术设计规划书

**研究主题：基于局部频带能量感知与空间自适应增强的跨尺度小波特征融合网络**

**英文暂定名称：** YOLOv12-WSCF v2: Local Frequency-Aware Spatial Enhancement and Cross-Scale Fusion

**项目类型：** 目标检测模型结构优化与消融实验研究

**设计状态：** 待实现与实验验证

## 第一章：研究背景与问题分析

### 1.1 现有 YOLOv12-WSCF 模型结构

现有模型以 YOLOv12-turbo 为基础，在原始 RGB 输入旁增加四级 Haar 小波分解分支，并通过四条路径将小波特征注入主干网络。

具体包括：

- W1 → P1：P1WaveletFusion，采用投影与卷积融合。
- W2 → P3：CrossScaleFusion，使用 P3 作为 Query、W2 作为 Key/Value。
- W3 → P4：CrossScaleFusion，使用 P4 作为 Query、W3 作为 Key/Value。
- W4 → P5：CrossScaleFusion，使用 P5 作为 Query、W4 作为 Key/Value。

三个 CrossScaleFusion 均采用局部窗口多头交叉注意力，并通过残差连接将注意力结果注入原始主干特征。

这一结构的初衷是利用固定 Haar 小波分解提供的多尺度频率信息，弥补 CNN 主干在特定频率和方向信息表达上的潜在不足。

### 1.2 现有模型的问题

根据目前的代码与训练记录，主要存在以下几个需要实验验证的结构性问题。

**问题一：频带增强缺乏空间差异性。**

现有 SubbandGRNv3 先对原始 RGB 图像执行全局平均池化，再通过 MLP 为各频带、各颜色通道预测缩放系数。

其输出为：

```
S ∈ R^(B×12×1×1)
```

这意味着，同一小波通道的所有空间位置使用相同的缩放系数。

但目标图像中，不同空间区域的频率信息具有明显差异。例如目标轮廓、背景纹理、平滑区域和噪声区域可能需要不同的增强策略。

全局通道缩放无法直接表达这种空间差异。

**问题二：频带调制缺少直接的频率统计依据。**

当前 GRN 根据原始 RGB 图像的全局平均值预测权重，没有直接利用对应频带的局部系数分布。

因此，模型不一定能够有效区分不同图像位置上的高频响应强度。

**问题三：小波物理频率信息与 CNN 语义特征之间存在表示差异。**

W2、W3、W4 来源于固定 Haar 滤波器，它们的频带具有明确的数学含义。

CNN 主干特征则通过多层可学习模块获得，具有更复杂的上下文和语义信息。

二者虽然可以通过注意力实现融合，但固定频域信息是否需要先进行任务相关的空间增强，仍然需要研究。

**问题四：多层零初始化可能影响新增分支的早期优化。**

现有 GRN 的最后一层权重初始化为零，CrossScaleFusion 的输出投影也初始化为零。

该设计有利于保护原始模型输出，但会使小波频带门控在训练初期受到下游输出投影的梯度限制。

这不是必然造成精度下降的原因，但需要通过梯度监控和初始化消融确认。

### 1.3 研究目标

本项目不改变跨尺度注意力这一核心设计，而是研究以下问题：

1. 如何利用局部频带能量保留空间位置差异？
2. 如何为不同位置、不同小波频带生成自适应增强权重？
3. 如何维持 LL、LH、HL、HH 四个频带的结构含义？
4. 如何将增强后的频域信息传递给现有 CrossScaleFusion？
5. 如何保证新结构在训练初期稳定优化，并验证其对检测精度的贡献？

最终目标是构建一个具有明确分工的处理流程：

**固定 Haar 分解 → 局部频带统计 → 空间频带增强 → 跨尺度语义注意力 → YOLO 目标检测。**

## 第二章：总体网络架构设计

### 2.1 总体设计原则

新模型采用最小必要修改原则：

- 保留 YOLOv12 原始主干结构和检测头。
- 保留四级 Haar 小波分解。
- 保留 W1、W2、W3、W4 的特征注入层级。
- 保留原有 CrossScaleFusion 的局部交叉注意力。
- 优先只修改 W2、W3、W4 的频带增强机制。
- 先不改变损失函数、数据增强和训练超参数。

这样可以在相同实验条件下，明确分析空间自适应频带增强是否有效。

### 2.2 推荐网络结构

输入 RGB 图像经过两条并行路径。

**路径 A：YOLOv12 原始主干。**

RGB → P1 → P2 → P3 → P4 → P5

**路径 B：多级 Haar 小波分支。**

RGB → 固定 Haar 分解 → W1、W2、W3、W4

其中：

- W1 继续通过原有 P1WaveletFusion 注入 P1。
- W2 先通过新设计的频带空间增强模块，再进入 P3 对应的 CrossScaleFusion。
- W3 先通过新设计的频带空间增强模块，再进入 P4 对应的 CrossScaleFusion。
- W4 先通过新设计的频带空间增强模块，再进入 P5 对应的 CrossScaleFusion。

三个 CrossScaleFusion 分别完成：

```
P3' = CSF(P3, W2')
P4' = CSF(P4, W3')
P5' = CSF(P5, W4')
```

这里的 W2'、W3'、W4' 表示完成空间频带增强的小波特征。

### 2.3 特征尺寸与接口

以 640×640 RGB 输入为例：

| 分支 | 输入尺寸 | 输出尺寸     | 融合目标 |
| ---- | -------- | ------------ | -------- |
| W1   | 640×640  | B×12×320×320 | P1       |
| W2   | 640×640  | B×12×160×160 | P3       |
| W3   | 640×640  | B×12×80×80   | P4       |
| W4   | 640×640  | B×12×40×40   | P5       |

新增空间频带增强模块必须满足：

**输入与输出张量尺寸完全相同。**

例如：

```
W3: (B,12,80,80) → SpatialGate → W3': (B,12,80,80)
```

从而无需修改 CrossScaleFusion 原本的特征输入接口。

## 第三章：局部频带能量感知模块设计

本项目建议新增模块：

**Local Subband Energy Estimation（LSEE）**

即局部子频带能量估计模块。

### 3.1 输入特征

对于第 l 级 Haar 小波：

```
W_l = Concat(LL_l, LH_l, HL_l, HH_l)
```

每个频带包含三个 RGB 通道，因此：

```
W_l ∈ R^(B×12×H_l×W_l)
```

为了保留频带结构，将输入重组为：

```
W_l → (B,4,3,H_l,W_l)
```

这里的 4 对应四个频带，3 对应每个频带的 RGB 三通道。

### 3.2 局部频带能量计算

对于第 b 个频带，在空间位置 (h,w) 上定义：

```
E_b(h,w) = [1/(C×k²)] × Σ_c Σ_(u,v)∈Ωk |W_b(c,h+u,w+v)|²
```

其中：

- b：LL、LH、HL、HH 四个频带之一。
- C：每个频带的颜色通道数，当前为 3。
- k：局部窗口边长。
- Ωk：以当前位置为中心的 k×k 邻域。
- h、w：当前空间位置。
- u、v：局部窗口内的坐标偏移。
- W_b：对应频带的小波系数。
- E_b：该频带在当前位置附近的平均平方系数。

这个公式用于统计局部频率响应的强弱。

需要强调的是，这里的能量是一种频率统计量，并不是直接的目标重要性得分。

### 3.3 默认局部窗口

第一版使用：

```
k = 3
```

也就是 3×3 局部窗口。

选择原因：

- 能够感知当前位置和邻近位置的频率响应。
- 保留原始小波特征图的空间分辨率。
- 计算复杂度相对较低。
- 可以与现有 CrossScaleFusion 的 3×3 注意力窗口进行关联分析。

后续进行 k=1、3、5 的消融实验，检验局部统计区域大小的影响。

在边界位置推荐采用反射填充，避免固定补零对边缘局部能量引入额外偏差。对于过小的特征图需要提供安全的 padding 回退方案。

### 3.4 能量图输出

对 LL、LH、HL、HH 分别计算局部能量：

```
E = Concat(E_LL, E_LH, E_HL, E_HH)
```

得到：

```
E ∈ R^(B×4×H_l×W_l)
```

例如 W3：

```
E_W3 ∈ R^(B×4×80×80)
```

这四个通道分别保留四类频带在每个空间位置附近的响应强度。

与原来每个频带仅使用一个全局统计量相比，现在可以描述频率响应的空间分布。

### 3.5 能量数值变换

为减小不同图像和不同频带响应量级造成的影响，第一版建议使用：

```
Z = log(1+E)
```

这里的 `log` 为自然对数。

该变换可以压缩较大的能量值，降低极端响应对后续卷积网络的影响。

另设计一个可选的相对频带能量版本：

```
D_b = log(E_b+ε) - (1/4)Σ_j log(E_j+ε)
```

其中 ε 是防止对零取对数的小常数。

该公式描述当前位置某个频带相对于其他频带的对数能量差异。

**第一版只使用 log(1+E)，不要同时引入两种归一化。** 相对频带能量作为后续独立消融实验。

## 第四章：空间自适应频带增强模块

建议新增：

**Spatial-Adaptive Subband Gating（SASG）**

即空间自适应子频带门控模块。

### 4.1 设计目的

原始 GRN 的频带权重：

```
S_global ∈ R^(B×12×1×1)
```

建议的新频带权重：

```
S_spatial ∈ R^(B×4×H_l×W_l)
```

这意味着同一频带在不同空间位置上，可以使用不同的增强系数。

同时，第一版让每个频带内部的三个 RGB 通道共享空间权重。

这是为了保留四个频带的分组结构、降低新增参数量，并减少通道之间过度自由的独立缩放。

### 4.2 门控网络

输入：

```
Z ∈ R^(B×4×H_l×W_l)
```

通过轻量级卷积网络：

```
Conv(4→16, 3×3) → SiLU → Conv(16→4, 1×1)
```

得到四张空间响应图：

```
G ∈ R^(B×4×H_l×W_l)
```

这里的 16 为初始建议的隐藏通道数，需要通过实验确认。

### 4.3 空间门控权重

采用有界残差门控：

```
S = 1 + β × tanh(G)
```

其中：

- S：空间频带缩放权重。
- β：控制调制幅度的超参数。
- tanh：将输出限制在 -1 到 1 之间。
- 1：保证权重围绕恒等映射变化。

第一版建议：

```
β = 0.2
```

因此：

```
0.8 < S < 1.2
```

权重大于 1 时对应增强，小于 1 时对应抑制。

这个范围并不是理论最优值，而是限制初始实验扰动幅度的工程选择。

### 4.4 频带增强

针对四个频带：

```
LL' = S_LL × LL
LH' = S_LH × LH
HL' = S_HL × HL
HH' = S_HH × HH
```

这里的每张空间权重图共享给对应频带的三个 RGB 通道。

最后：

```
W_l' = Concat(LL', LH', HL', HH')
```

输出仍然是：

```
W_l' ∈ R^(B×12×H_l×W_l)
```

该设计保留了四个频带的分组结构，同时允许在空间不同位置对各频带进行独立调制。

### 4.5 对频带结构的保护

需要明确：门控后的系数不再等同于未经修改的正交 Haar 分解系数。

不过，本研究的目的并非保持小波的完美可逆重建，而是将其作为目标检测的频域先验。

因此，建议保留以下约束：

1. 固定 Haar 滤波器不参与训练。
2. 分别计算四个频带的局部能量。
3. 先在频带分组内进行空间调制，再交给后续可学习投影。
4. 调制权重保持在可控范围。
5. 不将门控后的 LL 继续用于下一层 Haar 分解。

第五条尤其重要。

W2、W3、W4 应始终由原始递归 Haar 分解得到，即下一层分解使用未经门控修改的 LL。

这样能够保持不同层级 Haar 分解的固定物理定义，避免前一级门控改变后一级小波系数的生成过程。

## 第五章：CrossScaleFusion 保留与协同设计

### 5.1 保留原有注意力结构

CrossScaleFusion 是本研究的核心跨尺度融合模块。

新方案不取消它，也不在第一阶段更改其窗口大小、头数或注意力计算方式。

对于 P4 和 W3：

```
Q = Proj_Q(P4)
K = Proj_K(W3')
V = Proj_V(W3')
```

随后从 W3' 中为每个 P4 Query 提取对应的 3×3 局部窗口。

对于每一个 Query，计算：

```
Attention(Q,K,V) = Softmax(QKᵀ/√d) V
```

其中：

- Q：主干特征生成的查询向量。
- K：增强后小波特征生成的键向量。
- V：增强后小波特征生成的值向量。
- d：每个注意力头的向量维度。
- Softmax：在对应局部窗口内形成归一化注意力权重。

最后通过可学习输出投影进行残差融合：

```
P4' = P4 + Proj_Out(Attention(Q,K,V))
```

P3 和 P5 的融合采用同样逻辑。

### 5.2 两个模块的职责划分

**SASG 负责频域内部的选择。**

它根据局部频带响应，学习每个位置的 LL、LH、HL、HH 应该如何调制。

**CrossScaleFusion 负责跨尺度特征交互。**

它以主干特征作为 Query，学习在对应的小波局部窗口中应该选择哪些信息。

二者的区别是：

- SASG 主要建模频带和空间位置之间的关系。
- CrossScaleFusion 主要建模主干语义特征和小波位置特征之间的关系。

二者存在互补的可能性，但也可能出现功能重叠。

因此，需要通过消融实验检验 SASG 是否能为已有 CrossScaleFusion 带来额外收益。

### 5.3 K/V 的增强策略

第一版：

```
K = Proj_K(W')
V = Proj_V(W')
```

即 K/V 都使用增强后的小波特征。

后续可分别验证：

- 仅增强 Key，Value 保持原始小波特征。
- 仅增强 Value，Key 保持原始小波特征。
- 同时增强 Key 和 Value。

这个实验有助于区分 SASG 对注意力位置匹配和信息传递的影响。

## 第六章：初始化与训练稳定性设计

### 6.1 空间门控初始化

建议将 SASG 最后一层卷积的权重和偏置初始化为零。

此时：

```
G = 0
tanh(G) = 0
```

所以：

```
S = 1
```

即：

```
W' = W
```

新增模块在初始状态下不会改变小波系数。

这一设计有利于减少早期扰动，但也会使 SASG 前面卷积层在第一次反向传播时暂时收不到梯度。

### 6.2 CrossScaleFusion 初始化

现有 CrossScaleFusion 使用零初始化输出投影：

```
Proj_Out.weight = 0
Proj_Out.bias = 0
```

因此初始融合结果为：

```
P' = P
```

这可以保护原始主干特征，但也意味着在第一次反向传播时，梯度无法穿过零权重输出投影继续传递给新增小波分支。

因此，SASG 和 CrossScaleFusion 同时使用零初始化，可能造成新增模块的早期学习延迟。

### 6.3 推荐初始化实验

设计两组方案。

**方案 I：严格恒等初始化。**

- SASG 最后一层权重为零。
- CrossScaleFusion 输出投影为零。
- 初始新增分支不改变主干输出。

优点是最大限度保留预训练网络行为。

**方案 II：近似恒等初始化。**

- SASG 最后一层使用小幅随机权重，偏置为零。
- CrossScaleFusion 输出投影使用较小的非零初始化。
- 保证初始特征扰动很小，但允许梯度较早流经新增分支。

这两个方案分别测试，不应该在第一轮实验中同时修改其他结构。

还需要在不同训练步记录：

- SASG 第一层与最后一层的梯度范数。
- CrossScaleFusion 的 Q/K/V 投影梯度。
- CrossScaleFusion 输出投影梯度。
- 融合残差相对于主干特征的幅值。

这样才能判断零初始化是否真正限制了模型优化。

## 第七章：代码修改方案

### 7.1 block.py

新增：

```
LocalSubbandEnergy
```

负责局部频带能量计算。

新增：

```
SpatialSubbandGate
```

负责根据局部能量生成空间门控权重。

建议设计的接口：

- 输入：12 通道小波特征。
- 输出：增强后的 12 通道小波特征。
- 可配置参数：局部窗口 k、隐藏通道数、门控幅度 β。
- 默认启用：k=3，hidden=16，β=0.2。

第一版不需要修改 CrossScaleFusion 的内部实现。

### 7.2 WaveletLevelBlock

建议为局部增强新增独立版本，例如：

```
SpatialWaveletLevelBlock
```

内部流程：

1. 接收四个未经增强的 Haar 子频带。
2. 将四个频带按照固定顺序拼接。
3. 计算局部频带能量。
4. 使用 SpatialSubbandGate 生成空间权重。
5. 对四个频带分别调制。
6. 输出增强后的小波特征。

旧版 WaveletLevelBlock 保留，方便后续进行原始 GRN 对照实验。

**注意：默认情况下新门控是替换 W2/W3/W4 上的全局 GRN，而不是在全局 GRN 后面继续叠加一个门控。**

这样可以准确判断改进收益来自哪里。

### 7.3 WaveletBranch

保留四级 Haar 分解的主逻辑。

第一版建议：

- level1：保留原有 GRN 和 P1WaveletFusion。
- level2：使用 SpatialWaveletLevelBlock。
- level3：使用 SpatialWaveletLevelBlock。
- level4：使用 SpatialWaveletLevelBlock。

这样既保留现有结构，又能集中验证 W2/W3/W4 的空间频带增强效果。

### 7.4 tasks.py

优先保持原有模块解析接口兼容。

如果 WaveletBranch 的类名和初始化参数不变，只替换其内部的 level2、level3、level4，一般不需要改变 YAML 的层索引。

新模块如果以独立 YAML 层形式插入，则必须同步修改 parse_model 的模块注册、通道推断和后续层索引。

第一版不推荐额外插入新层。

### 7.5 yolov12-wscf.yaml

建议在第一阶段保持现有结构的层索引、融合层级与检测头不变。

通过 WaveletBranch 内部的可配置策略启用或关闭局部频带增强。

推荐增加实验配置参数，用于控制：

- 是否启用 SASG。
- SASG 使用的局部窗口。
- 是否启用原始 GRN。
- 门控幅度 β。
- 是否使用近似恒等初始化。

### 7.6 预训练权重验证

这是正式训练前必须完成的工作。

现有 tasks.py 使用基于参数名称和形状匹配的权重重映射逻辑，因此不能仅凭 `strict=False` 下模型成功启动，就认为原版权重已经正确加载。

需要执行：

1. 记录预训练检查点与新模型的参数对应关系。
2. 验证原始主干的每个匹配参数确实来自预期层。
3. 验证 Detect Head 是否正确加载兼容参数。
4. 输出加载参数数量、跳过参数和未匹配参数清单。
5. 使用固定输入比较原始模型与严格恒等初始化模型的输出。

在模型结构、类别数和预处理一致的条件下，严格恒等初始化时，新模型应尽可能重现原始主干与检测头的推理结果。

若该测试失败，应先修复权重映射或网络结构，再开展性能实验。

## 第八章：训练与消融实验规划

### 8.1 实验原则

所有用于最终比较的模型必须统一：

- 数据集及训练、验证划分。
- 输入分辨率。
- 预训练权重来源。
- 模型尺寸版本。
- 优化器与学习率策略。
- Batch size 或等效梯度累积。
- 数据增强与关闭增强的时机。
- 随机种子。
- 训练 epoch。
- 验证脚本与推理设置。

正式结果推荐至少进行三个随机种子的重复训练，汇报均值与标准差。

### 8.2 第一阶段：结构有效性消融

| 实验 | 模型结构                              | 主要验证目标                   |
| ---- | ------------------------------------- | ------------------------------ |
| A0   | 原版 YOLOv12-turbo                    | 获得严格统一的基线             |
| A1   | 原始 WSCF                             | 复现当前模型                   |
| A2   | WSCF + 局部空间门控（不输入能量统计） | 验证空间门控本身是否有效       |
| A3   | WSCF + 局部能量 SASG                  | 验证局部频率统计的额外贡献     |
| A4   | WSCF + 全局频带能量门控               | 区分全局频率信息与局部频率信息 |
| A5   | WSCF + SASG + 近似恒等初始化          | 验证初始化策略                 |

所有 WSCF 实验均保留 CrossScaleFusion。

建议先以较短训练进行筛选，再选择表现较好的模型进行完整训练。

不能仅根据前 50 或 100 epoch 的排名判断最终优劣，因为现有模型在训练后期仍然能够持续提升。

### 8.3 第二阶段：门控超参数消融

确定 SASG 有效之后，再研究：

**局部窗口大小：**

```
k ∈ {1,3,5}
```

**门控幅度：**

```
β ∈ {0.1,0.2,0.3}
```

**能量输入形式：**

- `log(1+E)`。
- 相对对数频带能量。
- 局部能量与全局能量联合输入。

不建议一开始就进行全部参数的网格搜索，应采用逐项消融，降低训练成本。

### 8.4 第三阶段：多尺度贡献实验

保留 CrossScaleFusion，分别启用：

| 实验 | 局部增强位置 |
| ---- | ------------ |
| B1   | 仅 W2        |
| B2   | 仅 W3        |
| B3   | 仅 W4        |
| B4   | W2 + W3      |
| B5   | W2 + W3 + W4 |

未启用新增强的位置保持与原始 WSCF 相同的设置。

目的不是取消某一级小波分支，而是判断哪一级最值得采用空间自适应频带增强。

### 8.5 第四阶段：完整训练

建议按照以下流程：

**第一步：** 单元测试、模型构建和前向/反向传播验证。

**第二步：** 短周期可运行性测试，检测梯度异常、NaN、显存问题。

**第三步：** 100～150 epoch 的初步筛选。

**第四步：** 选择表现最有潜力的配置进行与基线一致的完整训练，例如 400 epoch。

**第五步：** 使用多个随机种子进行最终比较。

训练结束后，统一使用各模型的最佳检查点与最终检查点进行分析。

## 第九章：评估指标与模块可解释性分析

### 9.1 检测性能指标

主要评价指标：

- mAP50-95：最重要的综合检测指标。
- mAP50：辅助判断目标识别效果。
- Precision：误检情况。
- Recall：漏检情况。

进一步记录：

- AP_S：小目标精度。
- AP_M：中目标精度。
- AP_L：大目标精度。
- 各类别 AP。
- 不同 IoU 阈值下的检测表现。

小目标指标尤其值得关注，但不应预先假定小波增强一定会提高小目标精度。

### 9.2 模型效率

必须对比：

- 参数量 Params。
- 理论计算量 FLOPs。
- 推理延迟。
- 吞吐量 FPS。
- GPU 峰值显存。
- 训练单个 epoch 的耗时。

由于原始 CrossScaleFusion 使用局部窗口展开，额外空间门控虽然参数量可能不大，但仍需测量实际推理效率。

### 9.3 空间门控可视化

对于 W2、W3、W4，分别保存：

- LL 空间权重热力图。
- LH 空间权重热力图。
- HL 空间权重热力图。
- HH 空间权重热力图。
- 原始小波系数幅值图。
- 增强后的小波系数幅值图。

需要对比目标区域、目标边界和复杂背景区域。

可视化目的是分析模型学到了什么，不应仅凭热力图颜色判断有效性。

### 9.4 门控与注意力协同分析

建议同时记录：

**空间门控变化幅度：**

```
Mean(|S-1|)
```

用于判断门控是否已经偏离恒等映射。

**门控空间方差：**

```
Var_hw(S_b)
```

用于判断某个频带在不同空间位置上是否真的使用了不同权重。

**CrossScaleFusion 残差比例：**

```
R = ||P'-P||₂ / (||P||₂+ε)
```

用于衡量小波融合结果对主干特征的实际影响。

**注意力分布熵：**

用于分析 3×3 窗口内的注意力是否倾向于均匀分布，还是集中于少数位置。

需要结合检测指标一起解释这些统计量，不能简单认为门控方差越大、残差越大或者注意力越集中就越好。

## 第十章：风险分析与解决策略

### 风险一：背景高频噪声被过度增强

局部高频能量大，并不代表该区域一定属于检测目标。

应对方案：

- 将局部能量作为门控输入，而不是直接作为最终权重。
- 使用有界残差门控限制过度放大。
- 对比复杂背景与目标区域的空间权重分布。
- 第二阶段考虑引入主干语义指导。

### 风险二：低频 LL 占据较大的能量量级

递归 Haar 的 LL 分量可能在数值幅度上明显大于高频分量。

应对方案：

- 使用 log(1+E) 压缩动态范围。
- 检验相对频带能量归一化。
- 监测四个频带门控输出的分布。
- 不跨层级直接比较未经归一化的能量数值。

### 风险三：空间门控与跨尺度注意力产生功能重叠

CrossScaleFusion 本身已经具有空间注意力选择能力。

新增 SASG 可能带来额外收益，也可能只是重复完成已有工作。

应对方案：

- 比较原始 WSCF、普通空间门控和能量驱动门控。
- 分析门控空间变化与注意力权重。
- 若精度增益不足，则优先简化门控网络，而不是继续增加复杂度。

### 风险四：新增模块学习速度较慢

双重零初始化可能导致新增频带分支早期梯度较小。

应对方案：

- 记录首批次及前若干 epoch 的梯度。
- 比较严格恒等与近似恒等初始化。
- 不要同时随意改变学习率和初始化方式。

### 风险五：计算成本增加但 mAP 提升有限

应对方案：

- 优先使用四通道门控图，而不是直接生成 12 通道空间权重。
- 控制隐藏通道数。
- 对每一级独立进行增强收益比较。
- 把参数量、FLOPs 和延迟纳入最终模型选择标准。

## 第十一章：第二阶段扩展——语义引导空间频带增强

第一版 SASG 主要依赖局部小波能量。

如果后续发现其仍然容易强化背景纹理，则研究：

**Semantic-Guided Spatial Subband Gating（SG-SASG）**

即语义引导的空间子频带门控。

### 11.1 核心思想

由小波分支提供频率响应信息，由对应尺度的 YOLO 主干特征提供语义上下文。

以 W3 和 P4 为例：

```
E_W3 = LocalEnergy(W3)
F_P4 = Upsample(Proj(P4))
S = 1 + β × tanh(Gate(Concat(E_W3,F_P4)))
W3' = S × W3
```

随后仍然执行原有 CrossScaleFusion：

```
P4' = CrossScaleFusion(P4,W3')
```

这样空间门控可以同时参考：

- 局部频率变化。
- 主干网络学习得到的上下文信息。

### 11.2 与 CrossScaleFusion 的区别

SG-SASG 负责在交叉注意力之前进行频带预调制。

CrossScaleFusion 负责根据 Query 和局部 Key 之间的相关性完成最终特征交互。

两者可能互补，但也可能产生更明显的参数冗余。

因此，SG-SASG 是第二阶段研究内容，**不作为第一版 WSCF v2 的必选模块**。

## 第十二章：性能目标与验收标准

### 12.1 精度目标

当前历史实验最佳 mAP50-95 为 40.104%。

如果按照你此前提到的官方结果约 40.6% 作为参照，新模型可以将达到或超过 40.6% 设为阶段性性能目标。

但必须强调：这只是研发目标，不是预期必然达到的结果。

最终应以相同数据集、相同训练协议下重新训练的原版 YOLOv12 和原始 WSCF 为正式比较基线。

建议重点关注：

- 相较原始 WSCF 的平均 mAP50-95 是否稳定提高。
- 相较原版 YOLOv12 是否能够获得正向收益。
- 不同随机种子下改善是否一致。
- 精度收益是否能够覆盖新增计算成本。

### 12.2 模块验收标准

新模块应满足：

1. W2、W3、W4 的输入输出尺寸不变。
2. 固定 Haar 分解结果不被修改。
3. 初始门控权重接近 1。
4. 模型前向与反向传播正常。
5. SASG 与 CrossScaleFusion 参数能够获得有效梯度。
6. 训练过程中无持续 NaN 或异常梯度。
7. 门控图能够产生可测量的空间差异。
8. 与原始模型的预训练参数映射得到验证。

上述条件只能证明模块实现和优化过程基本正常，不代表必然提高目标检测精度。

### 12.3 研究成功标准

将研究结果分成三个等级。

**基础成功：**

模型正常训练，新门控确实表现出空间频带调制能力，相关消融能够解释其作用。

**性能成功：**

在严格统一实验设置下，新模型相对原始 WSCF 获得稳定的 mAP50-95 提升。

**综合成功：**

新模型在精度、计算效率、消融证据和模块可解释性上取得合理平衡，并形成可以复现的完整实验结果。

## 第十四章：最终推荐实施版本

建议把第一版 YOLOv12-WSCF v2 明确限定为以下结构：

**保留部分：**

- YOLOv12-turbo backbone。
- YOLOv12 原始检测头。
- 四级固定 Haar 小波分解。
- W1-P1 融合。
- W2-P3、W3-P4、W4-P5 三条跨尺度交叉注意力。
- 原始训练损失函数。

**新增部分：**

- 局部频带能量计算。
- 四频带空间门控。
- 有界残差调制。

**第一版默认超参数：**

| 参数                        | 建议初值   |
| --------------------------- | ---------- |
| 局部能量窗口                | 3×3        |
| 门控隐藏通道                | 16         |
| 门控输出通道                | 4          |
| 门控幅度 β                  | 0.2        |
| 门控激活函数                | tanh       |
| 能量预处理                  | log(1+E)   |
| 门控应用层级                | W2、W3、W4 |
| 原始 CrossScaleFusion       | 完整保留   |
| CrossScaleFusion 注意力窗口 | 3×3        |
| 小波滤波器                  | 固定 Haar  |

这些数值是首轮实验设置，不是已经经过优化的最优参数。

### 最终研究逻辑

本研究将原先基于全局 RGB 统计的频带缩放，改进为基于局部频带响应的空间自适应调制。

首先利用固定 Haar 小波分解获取多尺度方向频率信息；其次通过局部能量统计与可学习门控生成空间相关的频带增强权重；最后使用主干 Query 与增强后的小波 Key/Value 执行跨尺度局部交叉注意力，将频率信息与 YOLOv12 主干特征融合。

这一设计的核心假设是：

**显式的局部频率建模能够为跨尺度注意力提供更具空间差异性的频带表示，从而改善小波信息的利用效率。**

该假设需要通过受控消融和完整目标检测实验验证。

**最终建议：先实现 LocalSubbandEnergy + SpatialSubbandGate，保持 CrossScaleFusion 完全不变。确认有效后，再探索语义引导门控和注意力优化。**

这样能够最大程度保留你原始 WSCF 的核心研究思路，同时使新模型具有清楚的数学定义、模块职责、实现路径和实验验证体系。
